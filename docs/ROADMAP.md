# KhataFlow Roadmap

## Phase 0 — Repository
Public GitHub repository, documentation, license, contribution rules, issue/PR templates, CI.

## Phase 1 — MVP Foundation
App shell, responsive navigation, theme, Dexie, ledger master, opening DR/CR, validation.

## Phase 2 — Core Accounting
Receipt, Payment, voucher numbering, double-entry entries, running balance, Day Book.

## Phase 3 — Reports
Dashboard, receivable/payable, cash/bank, trader reports, Cash Book, Bank Book, Trial Balance, Account Summary.

## Phase 4 — Data Safety
JSON backup/restore, CSV export, validation, ledger archive.

## Phase 5 — Sharing
PDF ledger statement, share statement, WhatsApp-friendly statement.

## Phase 6 — PWA
Offline app shell, install UX, update handling, icons, offline improvements.

## Phase 7 — Localization
English + Hindi, currency abstraction.

## Phase 8 — Advanced Accounting
Journal, expense, income, additional reports, controlled reversal/cancellation.

## Phase 9 — Optional Cloud
Only after local-first MVP is stable: authentication, cloud database, sync, conflict handling, multi-device.

MVP must not depend on cloud services.
