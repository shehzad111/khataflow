# KhataFlow GitHub Repository Specification

## Recommended Repository
`shehzad111/khataflow`

The repository is intended to be public and open source.

## Root Files
- README.md
- LICENSE
- CONTRIBUTING.md
- SECURITY.md
- CODE_OF_CONDUCT.md
- CHANGELOG.md
- AGENTS.md

## .github
- ISSUE_TEMPLATE/
- workflows/
- pull_request_template.md

Issue templates:
- Bug Report
- Feature Request
- Accounting/Calculation Bug
- Documentation

## CI
Run:
- dependency install
- TypeScript check
- lint
- tests
- production build

## Releases
Use GitHub Releases and semantic versioning:
- v0.1.0
- v0.2.0
- v1.0.0

## Open Source Integrity
Only publish code and assets that the project maintainers are authorized to publish. Do not copy proprietary Smart Shiksha, Dairy Expert, client, or other private repository code.

## Maintainer Practice
Use genuine issues, pull requests, releases, and contributor activity. Do not manufacture stars, forks, issues, downloads, contributors, or adoption signals.
