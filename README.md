# KhataFlow

**Simple Khata. Clear Ledger.**

KhataFlow is an open-source, privacy-first, local-first digital ledger and simple double-entry accounting application built with React and TypeScript.

## Core
- Ledger types: General, Traders, Cash, Bank
- Trader roles: Customer, Supplier, Both
- Opening balance: DR/CR
- Vouchers: Receipt, Payment
- Every posted voucher must satisfy Total DR = Total CR
- React + TypeScript + Vite + PWA
- IndexedDB/Dexie for MVP local storage
- Future optional cloud sync

See `docs/` for the complete product, accounting, database, UI, technical, GitHub, and roadmap specifications.
